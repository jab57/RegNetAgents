# Reproducibility Guide

This document explains how to verify the claims in the RegNetAgents paper **without requiring Claude Desktop or complex setup**.

---

## Quick Start: Verify Paper Results (5 minutes)

The paper's main claims can be verified with a single command:

```bash
# 1. Clone repository
git clone https://github.com/jab57/RegNetAgents.git
cd RegNetAgents

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run verification script
python reproduce_paper_results.py
```

**Expected output:**
- ✓ Five-gene analysis completes in 15-30 seconds
- ✓ Regulatory roles match paper's classifications
- ✓ Therapeutic target prioritization runs for genes with >5 regulators
- ✓ Results saved to `results/paper_reproduction_results.json`

**No Claude Desktop required.** This script uses the core workflow directly.

## What Can Be Verified Without Full Setup

### ✅ **Core Analytical Claims** (No Claude Desktop)

The following can be verified using `reproduce_paper_results.py`:

1. **Network Analysis**
   - Gene regulatory role classification (hub regulator, heavily regulated, etc.)
   - Regulator/target identification from ARACNe networks
   - Network topology metrics (in-degree, out-degree)

2. **Therapeutic Target Prioritization**
   - PageRank-based ranking of upstream regulators
   - Network centrality calculations (degree centrality, out-degree)
   - Regulatory loss percentage estimates

3. **Pathway Enrichment**
   - Reactome API integration
   - Statistical significance (p-values, FDR)
   - Top 10 regulator/target selection for enrichment

4. **Performance Claims**
   - Execution time for 5-gene analysis (15-62 seconds claimed)
   - Parallel processing of multiple genes
   - Network cache loading performance

5. **Rule-Based Domain Analysis**
   - Cancer biology classification (oncogenic potential, therapeutic score)
   - Drug discovery assessment (druggability score)
   - Clinical relevance (biomarker type, actionability)
   - Systems biology (network centrality, cascade effects)

### 🔧 **LLM-Powered Features** (Requires Ollama)

The following require Ollama for LLM-generated scientific rationales:

- Detailed scientific justifications for classifications
- Natural language explanations of network patterns
- Literature-contextualized insights

**To enable LLM features:**
```bash
# 1. Install Ollama: https://ollama.com/download
# 2. Pull model
ollama pull llama3.1:8b

# 3. Set environment variable
echo "USE_LLM_AGENTS=true" > .env

# 4. Run analysis (now includes LLM rationales)
python reproduce_paper_results.py
```

**Note:** LLM features are optional enhancements. Core analytical claims are verifiable without them.

### 💬 **Conversational Interface** (Requires Claude Desktop)

The Claude Desktop MCP interface provides:
- Natural language queries (e.g., "Analyze TP53 in epithelial cells")
- Interactive exploration of results
- Conversational report generation

**This is a UI feature, not required for verification.**

## Common Issues

### **Import Errors**

```bash
ModuleNotFoundError: No module named 'langgraph'
```

**Solution:**
```bash
pip install -r requirements.txt
```

### **Network Cache Missing**

```bash
FileNotFoundError: network_index.pkl not found
```

**Solution:**
Network files should be included in the repository. If missing:
```bash
# Check Git LFS is installed
git lfs --version

# Pull large files
git lfs pull

# Verify files
ls models/networks/*/network_index.pkl
```

### **Reactome API Timeout**

```bash
Pathway enrichment failed: connection timeout
```

**Solution:** Check internet connection. Pathway enrichment requires API access.

**Workaround:** Results are still valid, just without pathway enrichment section.

### **Performance Slower Than Claimed**

If execution takes >62 seconds:
- Check system load (other processes running)
- Network speed (for Reactome API calls)
- First run may be slower (caching overhead)

**Note:** Second run should be faster due to gene ID caching.
